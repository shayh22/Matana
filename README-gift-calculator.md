# 🎁 כמה לתת במתנה? — מחשבון מתנות לאירועים

עמוד סטטי אחד (`index.html`) בעברית RTL, שמחשב כמה כסף מקובל לתת במתנה
בחתונה, בר/בת מצווה, ברית, חינה, אירוסין או יום הולדת.

**דמו:** https://shayh22.github.io/matana/

## מה יש בו

- בחירת סוג אירוע, מידת הקרבה, סוג המקום והאזור בארץ
- ספירת האורחים שמגיעים מטעמכם (מבוגרים / נוער / ילדים / פעוטות)
- התאמות: לא מגיעים לאירוע, אירוע יעד, מתנה בשם כל המשפחה ועוד
- חלוקת המתנה בין כמה משפחות, וסליידר תקציב
- רצפת חישוב לפי עלות מנה משוערת — כדי לא לתת פחות מהמנה
- שמירה אוטומטית של הבחירות ב-`localStorage`
- כפתור שיתוף: `navigator.share` אם נתמך, אחרת `wa.me` עם טקסט מוכן
- מצב כהה אוטומטי לפי הגדרות המערכת

## הרצה

אין build ואין תלויות — פשוט פותחים את `index.html` בדפדפן.
לפריסה: GitHub Pages מהשורש של הריפו (הקובץ `.nojekyll` מונע עיבוד של Jekyll).

## כוונון המספרים

כל טבלאות החישוב יושבות באובייקט `CONFIG` בראש ה-`<script>` שבתוך `index.html`:

| מפתח | מה זה |
|---|---|
| `events` | `base` = סכום התחלתי לאדם, `plate` = עלות מנה משוערת |
| `relations` / `venues` / `regions` | מקדמי הכפלה (`mult`) |
| `guests` | כמה "שווה" כל אורח בחישוב (`weight`) |
| `modifiers` | תיבות הסימון והמקדם שלהן |
| `budgets` | חמש רמות הסליידר |
| `roundTo` / `rangeDown` / `rangeUp` / `minGift` | עיגול, טווח ומינימום |

הנוסחה: `base × משקל האורחים × קרבה × מקום × אזור × התאמות × תקציב`,
עם רצפה של עלות המנה ועיגול ל-50 ₪.

המספרים הם המלצה בלבד, לא כלל.
